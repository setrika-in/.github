# Setrika.in

Aplikasi kasir dan pelacak proses untuk pemilik laundry. Pemilik bisa tahu siapa menerima, mencuci, menyetrika, dan mengantar tiap order, lengkap dengan jamnya. Pelanggan cukup menerima link status dan pesan WhatsApp, tanpa pasang aplikasi.
